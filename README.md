## Install / Instalação

### 1) Clone

```bash
git clone https://github.com/manansbdb/playwright-starter.git
cd playwright-starter
```

### Use / Usar

```bash
npm i
npx playwright install
npx playwright test
```

### Requirements / Requisitos

- `git`
- No paid services required / Sem serviços pagos
